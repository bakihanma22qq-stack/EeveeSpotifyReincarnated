EeveeSpotifyReincarnated

An iOS tweak for Spotify that unlocks premium-style listening and adds extra features such as custom lyrics, continuing the legacy of EeveeSpotify for newer Spotify versions.

View on GitHub

Custom lyrics providers

  • LRCLIB
  • Genius
  • PetitLyrics

Building the IPA

IPA packages are not distributed here. Fork the repository on GitHub and run the Create IPA Packages workflow from the Actions tab, following the instructions in the README.
